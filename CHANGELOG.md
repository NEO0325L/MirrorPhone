# Cambios

## 1.3.0 — 2026-11-04 — versión de prueba multiplataforma

- Receptor compartido para Windows 11 x64 y Linux Mint 22.x x64.
- Paquetes Linux DEB y tar.gz; Windows ZIP e instalador NSIS mediante compilación en Windows.
- Conserva la captura iOS, la adaptación de calidad y las correcciones de audio de la versión anterior.
- Interfaz de escritorio neutral respecto al sistema operativo.
- Protección frente al almacenamiento sin cifrar `basic_text` de Linux.
- Dependencias fijadas, pruebas del receptor y Worker, compilación con GitHub Actions.
- Fuentes de iOS y servidor incluidas; secretos, firma y dependencias binarias externas excluidos.
- Control Wi-Fi de teclado/ratón documentado como diagnóstico experimental.

Validación física de Linux Mint y Windows pendiente. Esta versión no garantiza latencia cero ni una frecuencia de cuadros constante.
